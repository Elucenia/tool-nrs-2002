# NRS-2002

[条件・出典・許諾](https://elucenia.org/ja/tools/nrs-2002)

## 使い方

ポータルでツールを使用するか、ローカルHTTPサーバー経由でindex.htmlを開いてください。言語を選択し、項目を入力して計算してください。

## 入力項目と単位

### 栄養状態の障害

`estado`

- `0` — なし：正常な栄養状態
- `1` — 軽度：3か月で体重減少\>5%，または先週の摂取量が必要量の50～75%
- `2` — 中等度：2か月で減少\>5%，またはBMI 18.5～20.5で全身状態不良，または摂取量25～60%
- `3` — 重度：1か月で減少\>5%（3か月で\>15%），またはBMI\<18.5で全身状態不良，または摂取量0～25%

### 疾患の重症度（必要量の増加）

`gravidade`

- `0` — なし：正常な栄養必要量
- `1` — 軽度：股関節骨折，急性合併症を伴う慢性疾患（肝硬変，COPD，血液透析，糖尿病，がん）
- `2` — 中等度：大きな腹部手術，脳卒中，重症肺炎，血液腫瘍
- `3` — 重度：頭部外傷，骨髄移植，APACHE II\>10のICU患者

### 年齢 ≥ 70 歳

`idade`

## 方法の版

NRS 2002/ESPEN Kondrup 2003：2領域0–3、年齢≥70で+1、合計0–7

## 記載された計算式

スコア=栄養状態の低下（0–3）+疾患重症度（0–3）+年齢≥70歳なら1点。合計0–7。

スコア≥3：栄養リスク。

## 限界・対象集団

NRS-2002は、栄養状態と疾患の重症度を組み合わせたリスクのスクリーニングです。その開発では、利益を得る可能性がより高い研究群を区別しました。合計点は個人の反応を保証せず、栄養補助の経路や量を処方するものでもありません。定義、適格性、年齢は版に対応する必要があります。
