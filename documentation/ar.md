# NRS-2002

[الشروط والمصادر والأذونات](https://elucenia.org/ar/tools/nrs-2002)

## المدخلات والوحدات

### اختلال الحالة التغذوية

`estado`

- `0` — غائب: حالة تغذوية طبيعية
- `1` — خفيف: فقدان وزن \> ٥% خلال ٣ أشهر أو تناول ٥٠ إلى ٧٥% من الاحتياج في الأسبوع الماضي
- `2` — متوسّط: فقدان \> ٥% خلال شهرين، أو BMI من ١٨٫٥ إلى ٢٠٫٥ مع تدهور الحالة العامة، أو تناول ٢٥ إلى ٦٠%
- `3` — شديد: فقدان \> ٥% خلال شهر واحد (\> ١٥% خلال ٣ أشهر)، أو BMI \< ١٨٫٥ مع تدهور الحالة العامة، أو تناول ٠ إلى ٢٥%

### شدة المرض (زيادة الاحتياجات)

`gravidade`

- `0` — غائب: احتياجات تغذوية طبيعية
- `1` — خفيف: كسر الورك أو مرض مزمن مع مضاعفة حادّة (تشمّع، COPD، غسيل دموي، سكّري، سرطان)
- `2` — متوسّط: جراحة بطن كبرى أو سكتة دماغية أو ذات رئة شديدة أو ورم دموي
- `3` — شديد: إصابة الرأس أو زرع نخاع العظم أو العناية المركّزة مع APACHE II \> ١٠

### العمر ≥ ٧٠ سنوات

`idade`

## إصدار الطريقة

NRS 2002/ESPEN Kondrup 2003: مجالان 0–3، العمر≥70 +1، المجموع 0–7

## المعادلة الموثقة

المقياس = تدهور الحالة التغذوية (0–3) + شدة المرض (0–3) + 1 نقطة إذا العمر ≥70 سنة. المجموع 0–7.

المقياس ≥3: خطورة تغذوية.

## الحدود والفئة السكانية

تتحرى NRS-2002 الخطر بالجمع بين الحالة التغذوية وشدة المرض. ميز تطويرها بين مجموعات دراسات ذات احتمال أكبر للاستفادة؛ ولا يضمن المجموع استجابة فردية، ولا يصف طريق الدعم التغذوي أو جرعته. يجب أن تتطابق التعريفات والأهلية والعمر مع النسخة.
